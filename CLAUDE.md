# agents-mesh

Multi-agent communication via filesystem for AI coding agents.

## Agent skills

Issues live in GitHub Issues at `luisestebanveragomez/agents-mesh`. Use the `gh` CLI. See `docs/agents/issue-tracker.md`.

Canonical role names map 1:1 to GitHub label strings (defaults). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
