# claude-peers

Multi-agent communication via filesystem. Allows AI coding agents (Claude Code, Gemini CLI, OpenCode, etc.) to communicate across terminals without the user as intermediary.

## Status

In development — v0.1.0

## Install

```bash
git clone git@github.com:your-org/claude-peers.git ~/.claude-peers-source
bash ~/.claude-peers-source/scripts/install.sh
```
